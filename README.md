# 盘感盲测台

[English](README.en.md)

**在线使用：<https://starsky233.github.io/Market-Sense-Blind-Test-Station/>**

在浏览器里检验自己的交易盘感。网站从历史 M1 K 线里随机抽一个时刻，只显示到这一刻为止的走势，日期隐藏。你判断做多、做空或不做，攒够几百题后，统计你的判断扣掉点差和滑点之后还剩多少，并和同一批时刻的随机方向对比。

## 怎么用

1. 打开上面的网址，点“载入 USDJPY 一年 M1 数据”，或者选择你自己导出的 M1 CSV。
2. 看图做判断：做空（S）、不做（N）、做多（L），把握程度按 1、2、3。
3. 答完会揭晓后面的走势，显示 15、30、60 分钟后的收益，以及按止盈止损计算的结果。
4. 点右上角“统计”查看汇总，可以把答题记录导出为 CSV。

## 功能

- K 线周期：M1、M5、M15
- 指标：EMA（可添加多条，周期可改）、布林带、成交量、RSI、MACD，参数都可以修改
- 画图工具：趋势线、水平线、斐波那契回撤
- 止盈止损：按 ATR 倍数或固定 pip 设置，一直持有到其中一边被触发，没有时间上限
- 抽题方式：随机时刻，或只抽急涨急跌；可以只抽指定的服务器小时
- 统计：毛收益、净收益、相对随机方向的超额、t 值和 95% 区间
- 界面支持中文和英文，打开时按系统语言自动选择，右上角可以切换

## 数据

仓库里的 `USDJPY_M1_last_year.csv` 是 MT5 导出的 USDJPY M1 数据，时间从 2025-11-11 到 2026-11-10，约 37 万根 K 线，列为 `time, open, high, low, close, tick_volume, spread, spread_px, real_volume`。

也可以用自己的数据，支持 MT5 和 pandas 导出的 CSV 格式。文件只在浏览器里读取，不会上传。数据和答题记录都保存在你自己的浏览器里。
